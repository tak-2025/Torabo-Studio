# エンコーダ

ロータリーエンコーダ（つまみ）を回したときの動作を、**レイヤーごと**に設定します。
再フラッシュせず BLE 経由でライブ編集でき、本体に保存されます。

## できること

- **回転方向ごとの割当** — 右回し（CW）と左回し（CCW）に、それぞれ機能を割り当てます。
- **プリセット** — 音量など、よく使う操作をワンクリックで割当。
- **カスタム** — 任意のキー／メディア操作を、回転の＋方向・−方向に割り当てます。

## 使い方

1. キーボードに接続し、**① 読み込む**で現在の設定を表示します。
2. レイヤーを選び、右回し・左回しに割り当てる機能を選びます。
3. **② 保存**で本体に書き込みます。

## 注意

- エンコーダを搭載したファームウェアでのみ、このタブが表示されます。
- ライブ編集には torabo-tsuki_ext_FW を含むビルドが必要です。
