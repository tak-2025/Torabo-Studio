# LED

状況に応じて LED の色と点灯パターンを切り替えるルールを設定します。
再フラッシュせず BLE 経由でライブ編集でき、本体に保存されます。

## 仕組み（ルール方式）

「**こういう状態のとき → この色・パターンで光る**」というルールを、左右それぞれの LED に
複数登録します。上から順に評価され、最初に条件へ一致したルールが使われます。

- **条件** — レイヤー／モディファイア（Ctrl・Shift など）／用途（使いどころ）の組み合わせ。
- **色** — 一覧から選択（自動色も選べます）。
- **点灯パターン** — 点灯・点滅などのパターン。

## 使い方

1. キーボードに接続し、**① 読み込む**で現在のルールを表示します。
2. ルールを追加し、条件と色・パターンを設定します。並べ替えで優先順位を調整できます。
3. **② 保存**で本体に書き込みます。

## 注意

- LED を搭載した半分（左／右）に対応するタブのみ表示されます。どちらの半分にも LED が無い
  ビルドでは、このタブは出ません。
- 登録できるルール数には上限があります。
- ライブ編集には torabo-tsuki_ext_FW を含むビルドが必要です。
