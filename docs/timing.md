# タップ反応

Hold-Tap（`&mt` / `&lt`）の判定時間と、キースキャンのデバウンス時間を設定します。
再フラッシュせず BLE / USB 経由でライブ編集でき、本体に保存されます。

## Hold-Tap

`&mt`（Mod-Tap）と `&lt`（Layer-Tap）は、それぞれ**ノード単位**（キーマップ全体で共通）の
設定です。キーマップでどちらかを使っている全てのキーに一括で反映されます（キーごとの個別設定は
できません）。

- **プリセット** — 「標準」「ロール誤爆防止」「ホームロウモッド」から選ぶか、下の詳細設定で
  カスタム値にします。
- **tapping-term-ms（長押しと判定するまでの時間）**
- **flavor（判定方式）** — hold-preferred（ホールド優先）/ balanced（バランス）/
  tap-preferred（タップ優先）/ tap-unless-interrupted（妨害されなければタップ）
- **quick-tap-ms** — 直前のタップから連打とみなす時間（無効化も可能）
- **require-prior-idle-ms** — 直前に何も押していない状態が必要な時間（無効化も可能）
- **positional（位置による判定調整）**
  - **retro-tap** — ホールドと判定された後に単独で離した場合、タップとして送る
  - **hold-trigger-on-release** — 他のキーが離されるまでホールド判定を待つ
  - **hold-while-undecided** — 判定中は他のキー送信を保留する
  - **hold-trigger-key-positions（対象キー位置）** — ここに挙げたキー位置と同時に押された
    ときだけホールドを優先します（未選択なら無効）。物理レイアウト上でクリックして選ぶことも
    できます。

## デバウンス

キーのチャタリング防止時間です。数字が大きいほど誤入力は減りますが、反応がわずかに遅くなります。

| 設定 | 内容 |
|---|---|
| press（押下時） | 押した瞬間のチャタリングを防ぐ時間 |
| release（離した時） | 離した瞬間のチャタリングを防ぐ時間 |

分割キーボードでは、左右それぞれの半身が自分のキースキャンを行っています。この設定が両半身に
反映されるかどうかはファームウェアの対応状況によります。接続すると Torabo Studio がキーボードに
問い合わせ、対応していれば「両方の半身に反映されます（接続のたびに central 側からもう一方へ
送られます）」、対応していなければ「central 半身（torabo-tsuki では右手側）のみに反映され、
split peripheral 側のデバウンスには届きません」という案内をこの画面に表示します。

## 使い方

1. キーボードに接続し、**① 読み込む**で現在の設定を表示します。
2. mt / lt それぞれのプリセットまたは詳細設定を調整します。必要ならデバウンス時間も調整します。
3. **② 保存**で本体に書き込みます。書き込みは即反映され、本体に保存されます。Hold-Tap は次の
   押下から新しい設定で判定されます。

## 注意

- このタブは、対応ファームウェア（`torabo-timing` / 分割機の場合は peripheral 側の
  `torabo-timing-split` も対）を含めてビルドしたキーボードでのみ表示されます。非対応の
  ファームウェアでは、タブごと表示されません。
- ライブ編集には torabo-tsuki_ext_FW を含むビルドが必要です。
