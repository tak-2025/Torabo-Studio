# トラックボール

トラックボールを回したときの動作を、**レイヤーごと・軸ごと**に設定します。
再フラッシュせず BLE / USB 経由でライブ編集でき、本体に保存されます。

## できること

- **軸（X/横・Y/縦）ごとの役割** — カーソル移動 / スクロール / 無効 などを割り当てます。
- **速度（step）** — 数字が大きいほど動きが鈍く（ゆっくり）なります。
- **方向の反転** — 軸ごとに動く向きを逆にできます。
- **オートマウスレイヤー（temp-layer）** — ボールを動かしている間だけ指定レイヤーに切り替え、
  止めると自動で戻ります。マウス操作用のレイヤー（クリックやスクロール）を自動で出すのに便利です。

## 慣性スクロール

スクロールを止めた後も、勢いに応じてしばらく滑り続ける「慣性スクロール」を設定できます。
スクロール（Scroll）を割り当てた軸にだけ効きます。

- **有効化トグル** — 慣性スクロールを使うかどうかをオン/オフします。
- **滑走の長さ** — 数字が小さいほど長く滑ります（1＝数秒 / 8＝標準・約0.8秒 / 32＝ほぼ即停止）。
- **開始しきい値** — この速さより遅い操作では滑りません。大きくすると、勢いよく弾いたときだけ
  滑ります。
- これはデバイスごとの設定です。
- 対応していないファームウェアでは、この項目のカードにファームウェア更新を促す案内が表示されます。

## 使い方

1. キーボードに接続し、**① 読み込む**で現在の設定を表示します。
2. レイヤーと軸を選び、役割・速度・反転を設定します。必要なら慣性スクロールも設定します。
3. 必要ならオートマウスレイヤーを有効にし、切り替え先レイヤーと戻るまでの時間を設定します。
4. **② 保存**で本体に書き込みます。

## 注意

- ライブ編集には、対応ファームウェアモジュール（torabo-tsuki_ext_FW）を含むビルドが必要です。
- 「速度」を極端に大きくしても動きが止まることはありません（安全側に設計されています）。
