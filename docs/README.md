# Torabo-Studio 各タブの使い方

Torabo-Studio の各タブの説明です。まず [../README.md](../README.md) の概要を読んでから、
使いたい機能のページへどうぞ。

## 共通の流れ

トラックボール・トラックパッド・エンコーダ・LED・マクロ・コンボの各タブは、
**キーボードに接続した状態**で次の手順で使います（再フラッシュ不要）。

1. **① 読み込む** — いまキーボードに入っている設定を BLE 経由で取得して表示します。
2. **編集** — 画面上で値を変更します（この時点ではまだ本体に反映されません）。
3. **② 保存** — 変更を本体に書き込み、電源を切っても消えないよう保存（NVS）します。

> 編集を始める前に必ず一度「① 読み込む」を押してください。現在値を土台にして編集するため、
> 読み込まずに保存すると意図しない設定で上書きされることがあります。

## 接続しているキーボードにより表示されるタブは変わります

torabo-tsuki のファームウェアは機能の組み合わせでビルドされるため、キーボードによって
搭載機能が異なります。Torabo-Studio は接続時にファームウェアへ問い合わせ、**そのキーボードが
実際に持つ機能のタブだけ**を表示します。使いたいタブが出ていない場合は、その機能を含めて
ビルドしたファームウェアが必要です。
