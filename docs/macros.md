# マクロ

複数のキー入力をまとめて再生する**ダイナミックマクロ（`&dmac`）**を編集します。
再フラッシュせず BLE 経由でライブ編集でき、本体に保存（NVS）されます。

## できること

- **マクロの作成・編集** — 一連のキー入力を登録し、1つの操作として呼び出せます。
- **キーマップからの取り込み** — `keymap.keymap` ファイルから既存のマクロを読み込めます。
- キーマップ側で `&dmac <番号>` を割り当てると、そのキーでマクロを呼び出せます。

## 使い方

1. キーボードに接続し、**① 読み込む**で現在のマクロを表示します。
2. マクロを追加・編集し、送りたいキー入力を並べます。
3. **② 保存**で本体に書き込みます。

## 注意

- 「ダイナミック」マクロなので、**再フラッシュせずに**内容を差し替えられます。
- ライブ編集には torabo-tsuki_ext_FW を含むビルドが必要です。
