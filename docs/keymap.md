# キーマップ

キー配置（キーマップ）とレイヤーを編集します。これは ZMK Studio 標準の機能で、
torabo-tsuki 専用の追加タブとは別に、すべての ZMK キーボードで使えます。

## できること

- **レイヤーごとのキー割当** — 各キーに「何を入力するか」を割り当てます。
- **キーの選択** — キーを選ぶとピッカーが開き、文字・記号・修飾キー（Ctrl/Shift など）・
  メディアキー・レイヤー切替などから選べます。
- **レイヤーの追加・並べ替え・名前付け** — 用途ごとにレイヤーを分けられます。

## 使い方

1. キーボードに接続します。
2. 編集したいレイヤーを選びます。
3. 変更したいキーをクリックし、ピッカーから割り当てる機能を選びます。
4. 変更は接続中のキーボードに反映されます。恒久保存は ZMK Studio の保存操作に従います。

> 「レイヤー」は、Fn キーのように一時的に切り替わるキー配置のセットです。
> 例えば通常レイヤーでは文字入力、別レイヤーでは矢印や記号、といった使い分けができます。

|---|---|---|

| モード（レイヤー） | レイヤー | 切り替わるキー配置のセット |
