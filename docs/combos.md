# コンボ

複数のキーを**同時押し**したときに機能を発火する**コンボ**を編集します。
再フラッシュせず BLE 経由でライブ編集でき、本体に保存（NVS）されます。

## できること

- **同時押しの登録** — キー位置の組み合わせを選び、同時に押したときの動作を割り当てます。
- **発火する動作** — キー入力（kp）／レイヤー操作（mo・to・tog）／ダイナミックマクロ（&dmac）
  などを割り当てられます。

## 使い方

1. キーボードに接続し、**① 読み込む**で現在のコンボを表示します。
2. コンボを追加し、同時押しするキー位置と発火する動作を設定します。
3. **② 保存**で本体に書き込みます。

## 注意

- ファームウェア側に `CONFIG_ZMK_DYNAMIC_COMBOS`（`torabo-combos` スニペット）が必要です。
  未対応のビルドではこのタブは表示されません。
- ライブ編集には torabo-tsuki_ext_FW を含むビルドが必要です。
