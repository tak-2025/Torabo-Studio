# トラックパッド

トラックパッドの動きとジェスチャを、**デバイスごと・レイヤーごと・軸ごと**に設定します。
再フラッシュせず BLE 経由でライブ編集でき、本体に保存されます。

## デバイスの選択

左右それぞれのパッドや、拡張 FPC 接続のパッドなど、キーボードに搭載されているパッドを
ドロップダウンで選んで個別に設定できます（表示名はファームウェアが申告した「左/右・接続・種類」から生成）。

## 軸ごとの「機能」

各レイヤーの **横方向（X）** と **縦方向（Y）** に、指を動かしたときの動作を割り当てます。

| 機能 | 動作 |
|---|---|
| カーソル移動（Move） | 通常のポインタ移動 |
| スクロール（Scroll） | スクロール（横方向 X＝横スクロール／縦方向 Y＝縦スクロール） |
| 音量／明るさ／ズーム／ブラウザ 進む・戻る | スワイプでよく使う操作を発火（プリセット） |
| カスタム | スワイプの＋方向・−方向に任意のキー／behavior を割当 |
| 無効（Off） | その軸の入力を無効化 |

- **速度（step）** — 数字が大きいほど鈍くなります。
- **方向の反転** — 軸ごとに向きを逆にできます。

## ジェスチャ

タップ・2本指タップ・長押し（ホールド）・ダブルタップに、それぞれ任意のキー／behavior を
割り当てられます。

## 使い方

1. キーボードに接続し、**① 読み込む**で現在の設定を表示します。
2. デバイス・レイヤー・軸を選び、機能／速度／反転を設定します。必要ならジェスチャも設定します。
3. **② 保存**で本体に書き込みます。

## 注意

- スクロールの向きは軸に対応します（横方向 X＝横スクロール／縦方向 Y＝縦スクロール）。
- 保存には対応する新しいファームウェア（トラックパッド v2）が必要です。未対応のファームウェアでは
  読み込みはできても保存が拒否されます（本体の設定は保護されます）。
- ライブ編集には torabo-tsuki_ext_FW を含むビルドが必要です。
