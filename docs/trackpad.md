# トラックパッド

トラックパッドの動きとジェスチャを、**デバイスごと・レイヤーごと・軸ごと**に設定します。
再フラッシュせず BLE / USB 経由でライブ編集でき、本体に保存されます。

## デバイスの選択

左右それぞれのパッドや、拡張 FPC 接続のパッドなど、キーボードに搭載されているパッドを
ドロップダウンで選んで個別に設定できます（表示名はファームウェアが申告した「左/右・接続・種類」から生成）。

## 軸ごとの「機能」

各レイヤーの **横方向（X）** と **縦方向（Y）** に、指を動かしたときの動作を割り当てます。

| 機能 | 動作 |
|---|---|
| カーソル移動（Move） | 通常のポインタ移動 |
| スクロール（Scroll） | スクロール（横方向 X＝横スクロール／縦方向 Y＝縦スクロール） |
| 音量／明るさ／ズーム／ブラウザ 進む・戻る | スワイプでよく使う操作を発火（プリセット） |
| カスタム | スワイプの＋方向・−方向に任意のキー／behavior を割当 |
| 無効（Off） | その軸の入力を無効化 |

- **速度（step）** — 数字が大きいほど鈍くなります。
- **方向の反転** — 軸ごとに向きを逆にできます。

## ジェスチャ

タップ・2本指タップ・長押し（ホールド）・ダブルタップに、それぞれ任意のキー／behavior を
割り当てられます。

## 慣性スクロール

スクロールを止めた後も、勢いに応じてしばらく滑り続ける「慣性スクロール」を設定できます。
スクロール（Scroll）を割り当てた軸にだけ効きます。

- **有効化トグル** — 慣性スクロールを使うかどうかをオン/オフします。
- **滑走の長さ** — 数字が小さいほど長く滑ります（1＝数秒 / 8＝標準・約0.8秒 / 32＝ほぼ即停止）。
- **開始しきい値** — この速さより遅い操作では滑りません。大きくすると、勢いよく弾いたときだけ
  滑ります。
- これらはすべて**デバイスごと**の設定です（上で選んだデバイスに保存されます）。
- 対応していないファームウェアでは、この項目のカードにファームウェア更新を促す案内が表示されます。

## 使い方

1. キーボードに接続し、**① 読み込む**で現在の設定を表示します。
2. デバイス・レイヤー・軸を選び、機能／速度／反転を設定します。必要ならジェスチャや慣性スクロールも設定します。
3. **② 保存**で本体に書き込みます。

## 注意

- スクロールの向きは軸に対応します（横方向 X＝横スクロール／縦方向 Y＝縦スクロール）。
- 保存には対応する新しいファームウェア（トラックパッド v3）が必要です。未対応のファームウェアでは
  読み込みはできても保存が拒否されます（本体の設定は保護されます）。ファームウェアがこのアプリの
  知らないさらに新しいワイヤ形式を報告した場合も同様に、書き込みを拒否する読み取り専用表示に
  切り替わります（設定を壊さないための保護です）。
- 保存はデバイス単位ではなく**全デバイス一括**です。上のプルダウンでデバイスを切り替えて編集し、
  保存すると全デバイス分がまとめて書き込まれます。
- ライブ編集には torabo-tsuki_ext_FW を含むビルドが必要です。
