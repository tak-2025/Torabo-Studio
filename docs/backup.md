# バックアップ

各種設定・マクロ・コンボ・キーマップを1つのファイルに書き出し（エクスポート）、
また読み込み（インポート）します。設定の保存・移行・共有に使えます。

## できること

- **エクスポート** — 現在の設定をまとめて `.json` ファイル（v2 形式）に保存します。
- **インポート** — 保存した `.json` を読み込み、設定を復元します。
- **キーマップの書き出し** — `keymap.keymap` 形式でも書き出せます。

## 使い方

1. キーボードに接続します。
2. **エクスポート**でファイルに保存、または**インポート**で保存済みファイルを読み込みます。
3. インポートした内容は、各タブの**② 保存**で本体へ書き込みます。

## 注意

- バックアップファイルはテキスト（JSON）です。中身を直接編集する場合は形式を壊さないよう注意してください。
- 復元先のキーボードが対応機能を持たない場合、その項目は反映されません。
