# バックアップ

各種設定・マクロ・コンボ・キーマップを1つのファイルに書き出し（エクスポート）、
また読み込み（インポート）します。設定の保存・移行・共有に使えます。

## できること

- **エクスポート** — 現在の設定をまとめて `.json` ファイル（v4 形式）に保存します。
- **インポート** — 保存した `.json` を読み込み、設定を復元します。
- **キーマップの書き出し** — `keymap.keymap` 形式でも書き出せます。

## 使い方

1. キーボードに接続します。
2. **エクスポート**でファイルに保存、または**インポート**で保存済みファイルを読み込みます。
3. インポートした内容は、各タブの**② 保存**で本体へ書き込みます。

## v4 形式について（behaviors 名前テーブル）

ZMK は behavior に個体ごとの番号（behaviorId）を振っているため、番号だけでは別のビルドや
別のキーボードに持ち込んだときに正しく読み替えられません。v4 形式は、キーマップが使っている
behaviorId ごとに「書き出し元キーボードでの表示名」を対応表として同梱します。これにより、
インポート先が番号の割当が異なる別のビルド・別のキーボードでも、名前を手がかりに正しい
behavior へ読み替えて復元できます。v1〜v3 形式のファイルにはこの対応表がなく、書き出したのと
同じ個体に復元する場合のみ安全に使えます。

## 注意

- バックアップファイルはテキスト（JSON）です。中身を直接編集する場合は形式を壊さないよう注意してください。
- 復元先のキーボードが対応機能を持たない場合、その項目は反映されません。
- 読み込んだファイルが Torabo Studio が知っている版より新しい場合でも、読める範囲の項目だけを
  復元します（未知の項目はスキップされます）。
