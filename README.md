# Torabo Studio

**[torabo-tsuki](https://github.com/sekigon-gonnoc/zmk-keyboard-torabo-tsuki-lp) 向けに機能拡張した [ZMK Studio](https://github.com/zmkfirmware/zmk-studio) の非公式フォーク。**

**→ <https://tak-2025.github.io/Torabo-Studio/>**

インストール不要。**Chrome または Edge** で開くだけで使えます。

> ⚠️ 本プロジェクトは ZMK Project とは **提携・承認関係にありません**。ZMK Studio
> （Apache-2.0）を改変した非公式版です。問題報告は本リポジトリへお願いします。

ZMK Studio のキーマップ編集機能はそのままに、torabo-tsuki のトラックボール・トラックパッド・
エンコーダ・LED・タップ反応（Hold-Tap/デバウンス）・マクロ・コンボを **再フラッシュせず
BLE / USB 経由でライブ編集**するためのタブを追加しています。

## はじめかた

1. **キーボードを準備する。** キーマップ編集だけなら、そのままで使えます。
   トラックボールなどの独自設定タブも使いたい場合は、
   [torabo-tsuki_ext_FW](https://github.com/tak-2025/torabo-tsuki_ext_FW) のスニペットを含めて
   ビルドしたファームウェアを書き込んでおきます（同リポジトリの README に手順があります）。
2. **接続する。** 画面の **Bluetooth** または **USB** を押し、一覧から自分のキーボードを選びます。
   - ブラウザ版で Bluetooth 接続するとき、**接続中のキーボードは一覧に出てきません**。
     [下記の手順](#-ブラウザ版で-bluetooth-接続するときの制約)で一度だけ一覧に出す必要があります。
3. **編集して保存する。** 使いたいタブで設定を変え、**保存/書き込む**を押すとキーボード本体に書き込まれ、
   すぐ反映されます（再フラッシュは不要です）。設定を変える前や他の機種に設定を移管したい場合は「バックアップ」タブから
   `.json` に書き出して、インポートすることが可能です。

各タブの詳しい使い方は [docs/](docs/) を参照してください。

## ZMK Studio からの追加機能

| タブ | 内容 |
|---|---|
| **キーマップ** | ZMK Studio 標準のキーマップ／レイヤー編集（上流機能そのまま） |
| **トラックボール** | レイヤー/軸ごとの move・scroll・速度、temp-layer（オートマウスレイヤー）を BLE / USB でライブ設定。慣性スクロール（滑走の長さ・開始しきい値、デバイスごと）にも対応 |
| **トラックパッド** | レイヤー/軸ごとに カーソル移動・スクロール・エンコーダ風スワイプ・タップ/2本指タップ/ホールド等のジェスチャを BLE / USB でライブ設定。慣性スクロール（滑走の長さ・開始しきい値、デバイスごと）にも対応 |
| **エンコーダ** | ロータリーエンコーダの回転（CW/CCW）にレイヤーごとの behavior を割当。音量等のプリセット＋任意キー割当 |
| **LED** | 左右それぞれの LED を「条件（レイヤー/モディファイア/用途）→ 色・点灯パターン」のルールで設定 |
| **タップ反応** | Hold-Tap（`&mt` / `&lt`）の判定時間（tapping-term など）とキースキャンのデバウンス時間を BLE / USB でライブ設定。分割対応ファームウェアなら左右両半身に反映 |
| **マクロ** | `&dmac` ダイナミックマクロを BLE / USB でライブ編集（NVS 保存、再フラッシュ不要）。`keymap.keymap` からの取り込みにも対応 |
| **コンボ** | キー位置の同時押しで behavior（kp/mo/to/tog/&dmac）を発火するコンボを BLE / USB でライブ編集（NVS 保存、再フラッシュ不要） |
| **バックアップ** | 各種設定・マクロ・コンボ・キーマップを1ファイル（.json）にエクスポート/インポート。`keymap.keymap` 形式での書き出しも可 |
| **表示言語** | ヘッダーのトグルで 日本語 / English を切替（i18n） |

### 接続したキーボードに合わせてタブを出し分け

拡張ファームウェアで選択した機能について、**機能記述子**を設けており、
**そのキーボードが実際に持つ機能のタブだけ**を表示します（例：エンコーダ非搭載ならエンコーダ
タブは出ない、LED がどちらの半分にも無ければ LED タブは出ない）。この記述子を持たない
ファームウェアでは、全タブを表示します。

### ⚠ ブラウザ版で Bluetooth 接続するときの制約

**PC と接続中のキーボードは、ブラウザの機器一覧に出てきません。** ブラウザは「見つけられる状態」
の機器しか列挙できず、ZMK は接続中は見つけられる状態になりません。
接続するには、一覧を開いた状態でキーボードを一度見つけられる状態にします（アプリ内にも手順を
表示します）:

1. ブラウザ版で「Bluetooth」を押して一覧を開く
2. キーボードのプロファイル切替キー（`&bt BT_SEL`）で、使っていない別のプロファイルへ切り替える
3. 一覧に出てきたら、**元々使用しているプロファイルに戻す**（戻さないとキーボードを操作できません。
   一度出た機器は戻しても選べます）
4. 一覧から選んで接続

必要なのは接続時の一度だけで、繋がればセッション中はそのまま使えます。プロファイルの追加消費も
ありません。なお、これは Windows で確認した挙動です（他の OS は未検証）。

デスクトップ版はこの制約を受けません（OS のペアリング済み一覧から直接開けるため）。

## 開発・ビルド

```bash
npm install

# Web 開発サーバ
npm run dev

# デスクトップアプリ（開発）
npm run tauri dev

# デスクトップアプリ（配布ビルド）
npm run tauri build

# UI コンポーネントカタログ
npm run storybook
```

Rust ツールチェーン（Tauri 用）と Node.js が必要です。
